# เว็บไซต์บัตรคำ

ไฟล์นี้พร้อมใช้งานบน GitHub Pages

## เผยแพร่
1. สร้าง GitHub repository แบบ Public
2. อัปโหลด `index.html` ไว้ที่รากของ repository
3. ไปที่ Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / (root) → Save
6. รอ 1–5 นาที แล้วเปิดลิงก์ที่ GitHub แสดง

ข้อมูลของผู้ใช้แต่ละคนเก็บในเบราว์เซอร์ของอุปกรณ์นั้น ควรส่งออกไฟล์สำรอง JSON เป็นระยะ
